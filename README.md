# 💱 Convert Value

Projeto desenvolvido durante um curso de desenvolvimento web, com foco na prática de HTML, CSS e JavaScript.

## 📋 Sobre o projeto

O Convert Value é um projeto voltado à conversão de valores, desenvolvido para praticar conceitos fundamentais do desenvolvimento front-end, como manipulação de elementos HTML, estilização de interfaces e lógica com JavaScript.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📚 Objetivo de aprendizado

- Praticar a estruturação de páginas com HTML.
- Desenvolver interfaces utilizando CSS.
- Implementar lógica de conversão com JavaScript.
- Trabalhar com eventos e manipulação do DOM.

Projeto desenvolvido para fins educacionais.
